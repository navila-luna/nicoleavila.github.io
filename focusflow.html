FocusFlow

1 · Overview

FocusFlow began with a “what if?” question inspired by my experience with ADHD: What if I combined the Pomodoro technique with an interactive workspace where users could organize tasks and work through them in real time?

I wanted to bring structured planning and focused work into one experience, making it easier to move from planning to actually getting started.

The current prototype allows users to define goals, break them into subtasks, set priorities, track progress, and use a focus timer. Inspired by Agile sprint planning, I incorporated task statuses and interactive organization to give users more control over their workflow.

I also designed the AI assistance around microchunking, breaking overwhelming tasks into small, approachable actions. For example, instead of suggesting someone “write a report,” the first step might simply be opening a blank Google Doc.

I’m currently developing Brain Dump, an extension that will allow users to capture scattered thoughts through text or transcribed speech. AI will help organize those thoughts into actionable tasks that users can review and bring into the main planning interface.

While FocusFlow shares MoodBirdie’s interest in personal growth, it focuses specifically on task initiation, planning, and organization.

2 · Product flow

Capture

The in-progress Brain Dump is an optional way to capture typed or spoken thoughts, whether or not the user has already defined a goal.

Structure

Organize an objective into goals and subtasks, with optional AI assistance for creating a simpler starting plan.

Prioritize

Rank goals and subtasks so the next action is easier to identify.

Focus

Use the timer and task list together to work through one manageable step at a time.

3 · Product components

  • Working: Goals with nested subtasks, priority ranking, a focus timer, and AI-assisted plan writing on the main planning page.
  • Current AI: The planning feature uses the Gemini API with an earlier model. This phase prioritizes getting the product behavior and feature flow right before investing further in model selection, prompting, or tuning.
  • In progress: A redesigned Brain Dump interface, AI grouping that converts unstructured input into actionable items, and speech transcription for spoken capture.

Design and development

I created interface mockups in Figma before implementing FocusFlow with React, HTML, CSS, Zustand for state management, and Tone.js for timer sounds. I also used Claude as a development support tool.

4 · Lessons learned

The most valuable part of this project was learning how to carry a design from a Figma mockup through to a working interface that I implemented myself. Translating the visual plan into code required me to make decisions about layout, interaction, and component behavior rather than treating the mockup as a finished answer.

Building the product also pushed me to deepen my React skills. I explored more advanced concepts, including clearer state ownership and state-management best practices, so the interface could remain maintainable as its features and interactions became more complex.
